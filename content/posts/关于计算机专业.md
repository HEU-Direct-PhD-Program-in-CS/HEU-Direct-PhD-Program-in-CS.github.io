## 一，未来规划

两条主方向：就业，科研升学.  
 
短期目标上，也就是本科阶段是按自己要走的箭头选择要学习的内容，计算机专业本身是包罗万象的专业，学校教学内容与科研内容与就业应掌握技能，三者完全不相干。  

关于计算机专业素养：b站随便搜关键词去就行，一大堆升学承担的风险——学历贬值，时间成本.  

## 二，学习方法

多种学习方法选适合当前自己的混合学：

1. 博客，技术论坛：前期可以用csdn这种，专业性很强会有专门的论坛:<br>
    csdn网址： https://www.csdn.net/<br>
    利处：便捷，基本什么都有，全中文，而且有时有相关笔记<br>
    弊处：什么神人都有，内容良莠不齐，一些好的资源要收费<br>
2. 看书，看技术文档:<br>
    看书（线下水课的学习）<br>
    注意，真正0基础新大一看不了大部分有“入门”含义的专业书籍<br>
    这里推荐一下入门c语言的书籍（应对第一学期计算思维）<br>
    《21天学通c语言》<br>
    当然除了c语言更多书籍也可以去图书馆借阅<br>
    ![](/data/posts/关于计算机专业/图书馆icon.png)<br>
    
    （微信公众号常用：扫码借书，馆藏查询）<br>
    看技术文档或教程（线上学习）<br>
3. 关于技术文档:  <br>
    比如cpp ：[cppreference](https://en.cppreference.com/index.html), [cplusplus](https://legacy.cplusplus.com/);<br>
    关于教程类网站<br> 
    比如关于[vue3](https://www.runoob.com/vue3/vue3-tutorial.html)<br>
    事实上github也有相当多教程类<br>
4. 查询检索:<br>
    这部分往往关于具体问题的更多挖掘，或者学一个东西前的调研追问，或了解某些特定信<br> 
    视频网站：国内bilibili 国外Youtube （其他视频网站学习内容质量较低）<br>
    咨询平台：如知乎<br>
    校内讯息：校内群聊，校园集市等，部分学校官网比较难找（现在有AI小橙还好些）<br>
    文章查询：<br>
    国内：知网（注意校外访问输入学号登录下载文章就不花钱）<br>
    （多看些会发现不少灌水，已经相对的失去专业性了）<br>
    国外：https://liblsp.hrbeu.edu.cn/space/database 右侧栏<br>
    SCI,IEEE,ACM还算比较常用的，但后期基本都上arXiv 上找了（ https://arxiv.org/ ）<br>
    其他查询：AI（ai往往可以承担你一无所知领域或内容的查询）<br>
    直接用：<br>
    [Kimi](https://www.kimi.com/), [Deepseek](https://chat.deepseek.com/) <br>
    当然，外国的GPT,Claude等也很好用（在写代码上Claude感觉更不错）<br>
5. 上手项目实践练习<br>
    自己的一些想法，转变为有目标需求<br>

## 三，编程语言与开发工具

编程语言非常之多，分为高级语言，汇编语言，机器语言（对计算机不同层次视角说）  
现在高级语言也非常多，首先认识的一点是 你学的语言经常不是你学习工作使用的，要习惯这一点，语言只是载体，意识与思想才是根本。不同语言间大体还是一致的，语言的部分特性注意一下即可。  

1. C语言，编译语言，适合入门的高级语言，也是学校计算思维使用的语言  
2. C++, cplusplus，C的延申扩展，加上了面向对象编程的思想，基础东西不难，细枝末节的语法学不完<br>
    地位：悠久的C/C++至今仍因其运行效率的优势作为后端开发的主要语言<br>
    适合的IDE：小规模Dev，更大一些 visual studio 2022 ，vscode也可（配置环境变量对新人并不友好）<br>
    （IDE:集成开发环境，就好比写word文档而不是记事本一样）
3. Python，解释型语言，一行一行运行，因为各种可用库量大管饱，是现在科研（人工智能类）主要用的语言<br>
    IDE:pycharm,vscode等  
4. Java 也是当今就业所常用的语言之一

线上开发工具：  
如colab (jupytor上云端)  
（jupytor notebook 交互式开发）

## 六，开源

[Git]( https://git-scm.com/): 一个免费、开源的版本控制软件  

基本使用操作：  

``` bash
git add .          # 把改动放进“暂存区”——拍照前摆好姿势
git commit -m "描述" # 按下快门，生成一张快照
git push           # 把本地快照上传到远程仓库（GitHub/Gitee）
git pull           # 把远程最新改动拉回到本地
git checkout [-b]  # 签出分支
git branch []      # 分支操作
git stash          # 暂存
```

其他git操作有些可用于项目代码协作等  

[GitHub](https://www.github.com): 基于 Git 的云端仓库托管站 + 开源社区。服务器在国外。  
[Gitee（码云）](https://www.gitee.com)：中国版“GitHub”  
其他开源社区：往往有更强的专业性  

## 七，科研

- Q: 什么人做科研？
- A: 对升学有需求/吃这碗饭的人

- Q: 什么时候能开始做科研？
- A: 取决于你学个别专业能力，跟学校课程正常走的话，至少要大一下之后的数学及专业素养  
    （人工智能方向需求大一下高数，概率论与数理统计，线性代数）  
    （偏硬件或体系结构方向需求大一下计算机组成原理等及其他专业内容）  

- Q: 怎么理解科研？
- A: 无意义/低意义科研：最新理论的工程应用  
    较有意义的科研：先射箭再画靶的炼金术  
    更高意义的科研：理论，架构，基础性开创性工作  
    注：科研能力与实际做的有无意义无关  
    科研=理念发现+设计提出+实验验证+归纳总结  

科研工具？找自家导师，学长
