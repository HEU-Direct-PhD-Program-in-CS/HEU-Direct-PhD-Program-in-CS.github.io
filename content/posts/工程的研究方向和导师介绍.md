### 体系结构与嵌入式

作为计算机的看家专业与核心专业, 体系结构在任何时候都有其用武之地. 主要研究围绕如何让计算机更高效, 可靠, 通用, 易用.

包含的二级方向:

| 方向  | 概述 | 相关团队/教授 |
| :-:  | :-: | :-: | 
| 体系结构 | 围绕指令集和计算机系统的各子模块, 系统软件/库, 硬件模块设计, 软硬件交互等方向研究 | TODO |
| 传统编译 | 如何让人类编写的代码 **更高效** 的转化成计算机可执行的指令 | 吴艳霞 |
| 算子优化 | 通过编译方法在计算机运行的各过程中, 提高神经网络算法的运行效率, 由于神经网络有着许多特殊之处, 处理方式和传统编译有较大区别, 因此单列 | 吴艳霞 |
| `GPGPU`/`CPU`设计 | 计算机核心硬件设计(*不是制造!*), 其中难度上: `CPU` >> `GPGPU` | TODO |
| 存储系统 | 围绕计算机缓存, 内存, 磁盘, 数据库驱动软件等存储相关的模块进行研究, 目的是加速模块间的数据传输量和存储量 | 好像我们学校没有 |
